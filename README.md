# Voice to Text

A voice-to-text web app built with React + Vite using the browser's Web Speech API.

## Features
- Speak and see live text
- 100+ languages with a search box
- Copy and Clear buttons
- Dark and gold premium design

## Run locally
```bash
npm install
npm run dev
```
Open the localhost link in **Google Chrome** and allow microphone access.

## Push to GitHub

git init

git commit -m "Add voice to text React app"

git remote add origin https://github.com/YOUR-USERNAME/voice-to-text-react.git
